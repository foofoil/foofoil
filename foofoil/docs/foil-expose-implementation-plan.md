# App Exposé 总览实现

状态：已实现，界面统一由 AppKit 渲染。

## 入口与窗口

- “窗口 → 箔片总览”与可配置的全局快捷键使用同一入口，默认 ⌃⇧Esc；重复触发关闭。
- Carbon 热键无需输入监控或辅助功能权限，应用未激活时也能唤起总览。
- 只在当前活跃显示器展示一个 `FoilExposePanel`，集中呈现所有打开箔片及历史记录。
- 面板使用屏幕尺寸、无边框非激活样式和 `screenSaver` 层级，透明且不出现在窗口菜单中。
- 原生控制器先取得屏幕内容尺寸，再赋给面板，避免初始零尺寸。
- Esc 或切换到其他应用时关闭总览；系统面板展示期间让出焦点和事件处理。

## 代码职责

- `App/FoilExposeController.swift`：模型、条目快照、历史分类、键盘导航、面板生命周期，以及打开、改名、收藏和删除等回调。
- `Views/FoilExposeViewController.swift`：原生背景、标题、搜索输入、范围选择、剪贴板入口、分类按钮和提示层。
- `Views/FoilExposeGrid.swift`：`NSScrollView`、`NSCollectionView`、可复用的原生卡片及分区标题。
- `Views/FoilExposeThumbnailLoader.swift`：ImageIO 缩略图解码、缓存及并发限制。
- `AppDelegate+MenuSetup.swift` 与 `AppDelegate+MenuValidation.swift`：菜单入口和状态校验。

## 布局与更新

- 搜索栏固定在顶部，输入框直接使用原生第一响应者，并保留输入法组合文字和选区。
- 剪贴板入口与网格右边缘对齐；历史分类按钮位于历史标题同一行右侧，空间不足时只让分类区横向滚动。
- 分区标题包含类型图标和计数胶囊；打开箔片分区带分隔线。
- 网格列数由宽度计算，普通卡片与紧凑搜索结果使用各自列数。
- 模型通知在下一次主循环合并读取；结果内容变化才重载集合，键盘高亮不重建卡片。
- 滚动不发布卡片全局坐标或可见集，也不触发根界面的连续更新。
- 键盘移动高亮后，只露出一部分的卡片会最小滚动到完整可见；完全在视口外时才居中定位。
- 悬停和高亮使用图层动画；缩略图只复用已有历史数据，不抓取新的屏幕截图。

## 搜索与交互

- 搜索始终可用，输入 `/` 选择范围；范围、历史分类和收藏筛选复用同一业务模型。
- 文件和音乐结果保留异步搜索、状态提示与分组展开。
- 前 30 项按结果列表顺序固定分配 1–9、0，以及跳过导航保留字母后的 A–Z（C、D、G、H、I、J、K、L、M、O、Q、R、S、T、U、V、W、X、Y、Z）；滚动不重新编号。
- ⌃ + 编号直接选择对应条目，⌃P/N/F/B 优先用于方向导航，⌃A/⌃E 把高亮移到当前行首/行尾。
- 方向键、Return、Tab、翻页、输入法组合状态以及系统菜单快捷键统一由控制器处理。
- 右键支持收藏、改名和历史清理；分类清理遵循既有收藏保护规则。
- 选择条目后关闭总览，再激活原窗口、恢复历史内容或打开搜索结果。

## 验证

定向测试覆盖网格尺寸、原生视图树、屏幕尺寸、搜索同步、标题行布局、分类与收藏、固定编号和模型导航。

每次应用代码改动后运行 `./run` 构建启动，再检查菜单与快捷键开关、搜索、分类、滚动和条目激活。无新增权限、第三方依赖或远程数据处理。
