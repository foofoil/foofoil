## 系统与编辑

| 操作 | 快捷键 |
| --- | --- |
| 打开设置 | ⌘, |
| 退出应用 | ⌘Q |
| 隐藏其他应用 | ⌥⌘H |
| 撤销 / 重做 | ⌘Z / ⇧⌘Z |
| 剪切 / 复制 / 粘贴 | ⌘X / ⌘C / ⌘V |
| 全选 | ⌘A |

编辑快捷键用于文本输入或可选中的内容，是否可用取决于焦点和内容类型。隐藏不会关闭箔片或中断音频播放。

## 总览内的操作

- 方向键选择，Return 切换到选中的箔片；编号或字母可直接选择可见条目。
- `/` 进入搜索；搜索时 ⌃ + 编号或字母直接选择。
- Esc 退出搜索，再按 Esc 关闭总览。
- {{clipboardShortcut}} 打开剪贴板内容。
