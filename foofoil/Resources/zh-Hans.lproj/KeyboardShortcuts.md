# 快捷键一览

快速打开和 Exposé 搜索的 `/` 列表末尾依次为终端（terminal）和摄像头（camera），选择终端后显示打开终端对话框，选择摄像头后直接打开。

可在“设置 → 快捷键”中调整键位。除全局快捷键外，需浮箔处于前台；部分操作仅适用于特定内容。

⌘ Command · ⇧ Shift · ⌥ Option · ⌃ Control · Esc Escape · Space 空格 · Tab 制表键


下表会列出包括自动生成的无痕打开快捷键在内的默认快捷键与当前快捷键。

无痕箔不进入历史记录，退出后也不会恢复。可通过文件菜单的新建无痕箔、无痕打开剪贴板内容，或系统共享菜单的无痕箔打开。拖入无痕箔的内容及多文件分组创建的其他箔片均不会进入历史记录。通过“文件 → 转为无痕箔／转为普通箔”可双向转换当前箔；转为无痕箔会删除其历史记录，已收藏的箔不能转为无痕箔，操作结果会短暂提示。
普通打开操作只复用普通空箔；无痕打开会新建箔片。菜单和普通打开快捷键始终有痕，不受当前箔影响。文件菜单中按住 ⌥ 可显示无痕打开项。无痕快捷键由普通快捷键加 ⌥ 自动生成；普通打开快捷键不能含 ⌥。未设置无痕剪贴板全局快捷键时，⌥⌘V 为固定的应用内无痕剪贴板快捷键。无痕箔里的按钮始终无痕打开。空无痕箔显示脚印斜线图标，不展示历史卡片，也不提供最近历史的数字快捷键。

EPUB 上下章节切换遵循正文阅读顺序，不逐个切换小节。可通过“前往 → 上一章 / 下一章”操作，在“设置 → 快捷键 → 导航”中配置键位；到达首尾章节时不循环。

侧边导航栏获得键盘焦点时，↑ / ↓ 按可见行导航并打开选中的文件；← 折叠目录或移到父项；→ 和回车均可展开目录，目录已展开时进入首个子项，回车作用于文件时打开该文件。压缩包树和其他导航侧栏均适用，窗口和全屏模式行为一致。聚焦时选中项使用激活色，焦点移到正文或其他窗口后显示灰色。搜索框保留正常文本编辑按键。

导航列表另支持 ⌃P / ⌃B 上一项、⌃N / ⌃F 下一项。正文获得焦点时，只读文本、Markdown 预览和 EPUB 的 ↑ / ↓ 滚动正文；切换列表项请使用 ← / →、⌃P / ⌃N 或自定义的列表项快捷键。

## 总览内的操作

- 键盘高亮移到最顶端一行时，列表滚到顶部，完整显示顶部标题。
- 方向键选择；↑ / ↓ 按实际显示行移动，以卡片左边缘对齐；Return 切换到选中的箔片或打开选中的 Spotlight 文件，Spotlight 文件结果也支持方向键移动高亮；⌃ + 数字或字母可直接选择有编号的条目，包括屏外条目。前 30 项按列表顺序固定编号为 1–9、0，以及跳过导航保留字母后的 A–Z（C、D、G、H、I、J、K、L、M、O、Q–Z），不随滚动改变。
- 搜索框始终保持键盘焦点，Tab 和 Shift-Tab 不切换焦点；输入法组合文字时保留 Tab 行为。点击剪贴板按钮或使用其快捷键打开剪贴板内容，按住 Option 显示无痕打开及对应快捷键。
- ⌃P / ⌃N / ⌃F / ⌃B 将高亮项向上 / 下 / 右 / 左移动，优先于字母直选，搜索框保持聚焦。
- ⌃A / ⌃E 将高亮移到当前行首 / 行尾，搜索框保持聚焦。
- 搜索框自动显示并保持聚焦；输入 `/` 选择搜索范围。
- Esc 取消范围选择，否则关闭总览；输入法组合文字时优先交给输入法处理。
- ⇧⌘D 切换历史记录的“已收藏”筛选，可在“设置 → 快捷键”中修改。历史记录项高亮时，⌘Backspace 删除记录、⌘E 更改标题、⌘D 切换收藏、⌘I 打开箔信息；右键菜单显示图标和对应快捷键。输入法组合和分类选择期间保留输入行为。
- {{clipboardShortcut}} 打开剪贴板内容。

将 Apple Music 歌曲、专辑或公开歌单的分享链接粘贴到快速打开，预览后按回车即可打开音乐箔；「打开剪贴板内容」也会直接将这些链接作为音乐打开。明确输入链接不受 Apple Music 资料库搜索开关限制，仍需音乐访问授权及所在地区可访问的内容。分享内容无需先加入资料库，也可从历史记录恢复。

快速打开统一显示全部来源，不设分类标签；各组初始 12 条，「更多」每次增加 18 条，整个结果区最多 60 条。

存在的绝对路径、以 `~/` 开头的路径或 `file://` URL 会在快速打开中作为第一项，并在 Exposé 的范围下拉框中显示为「打开文件」或「打开文件夹」，按回车即可打开。可打开的网址会在 Exposé 的范围下拉框中显示为「打开网址」，快速打开则提供打开网址的结果。路径支持成对引号及终端风格的反斜杠转义；相对路径不会解析。

Apple Music 的快捷键入口与链接识别需要先在「设置 → 类型 → 音频与视频」开启默认关闭的「启用 Apple Music 资料库」。关闭时，快速打开和「打开剪贴板内容」将 Apple Music 分享链接作为普通网页处理。

可配置的“文档 / 字幕样式”命令在视频中打开字幕设置，在文档中打开文档样式。字幕样式和时间偏移全局保存。

字幕和文档样式均可保存为自定义主题。在“另存为主题”中选择已有主题可覆盖；右键点击自定义主题也可覆盖或删除。字幕主题保存完整设置，文档主题保存颜色、字体、字号与间距。

压缩包箔的“另存为”导出选中的文件、目录或根目录。压缩包导航面板中，上/下键选择条目，左键折叠或选择父目录，右键展开或选择首个子项，回车/空格打开选中项。焦点在正文时，EPUB 章节命令与 PDF 翻页命令作用于包内预览。导航搜索定位会展开完整祖先链。右键也可在原树中按需读取未打开的内层包，左键折叠时取消未完成的加载；搜索不会扫描未展开的包。


终端获得焦点时，窗口位置和移到下一个屏幕快捷键（包括自定义键位）仍然有效。Ctrl+A/E/P/N 等控制键优先交给 Shell/TUI。程序协商启用 Kitty 键盘消歧后，可区分 Ctrl+M 与回车、Ctrl+I 与 Tab；普通 Shell 输入保留传统编码。目前仅支持消歧能力（flag 1），主屏和备用屏分别保存模式栈。⌘C/⌘V 复制粘贴，内容放大／缩小调整终端字体。按住 ⌘ 拖动终端窗口不会选择文字。文档样式可调整终端主题、背景色、文字颜色、字体和字号，字体筛选与代码箔一样使用“仅显示等宽字体”。

搜索条在阅读区域顶部按需出现，不挤动正文。EPUB 搜索整本书，侧边栏的“搜索目录”只搜索目录标题。匹配关键字会高亮；高亮色可以在文档样式中设置，也会随自定义主题保存。

无痕切换快捷键在文本编辑器、Markdown 预览、终端或伴随导航栏获得焦点时均有效；长按不会反复切换。打开的面板保留自己的输入。

空箔顶部输入框复用快速打开搜索：↑ / ↓ 选择、回车打开、Tab 确认范围、Esc 清空。正文与 Markdown 源码只读。

空箔激活时始终聚焦搜索框；输入 `/` 后可用方向键选择搜索类型、操作或底部的功能开启项，回车执行，Esc 清空并保留输入焦点。

空箔的 `/ 更多选项` 提供网址输入和剪贴板搜索入口，网址位于目录后，剪贴板位于列表首位；支持回车确认，Apple Music 三类位于最后。

三个搜索入口中，输入 `/` 选择范围时，上下方向键可在首尾选项间循环；选择“剪贴板”后输入关键词筛选；方向键选择、回车打开。首次读取系统历史需为浮箔开启完全磁盘访问，未授权时仅搜索当前剪贴板。

空箔剪贴板按钮右侧的省略号会填入 `/剪贴板` 并聚焦搜索框，按回车确认范围。
