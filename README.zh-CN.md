# 浮箔 foofoil

**给你的桌面降维。**  
**Anything, right where you need it.**

[English](README.md)

浮箔是一款轻量级 macOS 悬浮工作空间。把文档、图片、网页、音视频和终端放进独立的极简窗口——「箔片」中，随手打开、搜索、置顶和切换，让需要的内容留在手边。

「浮箔」之名取自内容在桌面上的存在方式：它们像一张张轻薄的箔片，浮在工作区中，需要时触手可及，又尽可能不带来传统窗口的视觉负担及复杂的操作逻辑。

“箔”的意象也来自刘慈欣《三体》中的“二向箔”——将复杂的世界压成轻薄的一层。于是有了浮箔的 slogan：**给你的桌面降维。**

浮箔使用 SwiftUI 与 AppKit 构建，优先复用 macOS 原生能力，追求轻巧、自然的交互。界面支持英文与简体中文。

## 打开与搜索，一个入口

在空箔中直接输入，或按 **⌘P** 唤出快速打开：查找历史、本机文件和目录，输入网址或已有文件路径，找到后回车打开。按 `/` 可选择剪贴板、历史、文件、目录、网址、终端、摄像头等入口；启用 Apple Music 后，也能搜索资料库中的专辑、歌单和歌曲。

- **随手打开剪贴板。** ⇧⌘V 将复制的文件、文件夹、图片、网址或文字打开为箔片，自动识别 Markdown 和 HTML；有普通空箔时优先复用。
- **搜回看过的内容。** 历史搜索覆盖标题与已索引正文，包括设备端 OCR 识别的图片文字，以及从 PDF 和网页提取的文本。常用内容可以收藏，清理历史时保留。
- **接上系统工作流。** 拖放文件、目录或文字，从 Finder 服务打开多选项目，或通过支持的应用的系统共享菜单送入浮箔。

本机文件搜索使用 Spotlight，默认开启。剪贴板搜索提供当前内容，授予完全磁盘访问权限后还可搜索系统 Spotlight 保存的剪贴板历史。

## 总览：回到内容的中心

**无论正在使用哪个应用，按 ⌃⇧Esc，即可打开总览。** 它将已打开的箔片、历史和搜索汇集在一起，让你随时找到内容、切换任务，再回到手头的工作。

- **一眼找到正在用的箔片。** 集中查看已打开的内容，切换到目标箔片，或重新显示隐藏的窗口。需要让出桌面时，可以先隐藏，之后从总览找回。
- **重新打开历史与收藏。** 查找之前看过的内容，按 ⇧⌘D 筛选收藏，让常用资料随时可取。
- **直接搜索并打开。** 在总览中搜索历史和本机文件，也可输入网址或已有文件路径；按 ⇧⌘V 直接打开剪贴板内容。
- **全程用键盘完成。** 方向键选择、回车打开，按 ⌃ + 项目编号直接选取；打开总览即可直接输入搜索，`/` 用于选择搜索范围；Esc 取消范围选择，否则关闭总览。

快速打开适合直接寻找一份内容；总览则让你同时掌握已有箔片与可打开的资料，是日常切换和找回内容的主要入口。

## 让每张箔片待在合适的位置

箔片可以独立置顶、调整透明度，并按内容类型切换边框。把参考图留在设计稿旁、让文档靠在代码边，或把播放器缩到桌面角落，都有方便的操作方式。

| 操作方式 | 用途 |
| --- | --- |
| ⌘ + 拖动 | 拖动整张箔片，包括终端；无需寻找标题栏 |
| 触控板三指拖动 | 指针位于内容或侧栏上时，直接移动整张箔片 |
| ⌘ + 滚轮、双指捏合 | 按内容类型缩放图片、正文或调整窗口大小 |
| ⇧⌘+ / ⇧⌘− | 增大或缩小窗口 |
| ⌃⌥ + Q W E / A S D / Z X C | 按键盘三行对应屏幕九宫格，快速定位窗口 |
| ⌃⌥Tab | 将箔片移到下一块屏幕 |
| ⌘H / ⇧⌘H | 隐藏当前箔片 / 隐藏所有箔片，临时让出工作区 |

窗口移动和尺寸手势主要用于非全屏状态；缩放行为随内容类型和边框状态而异。在可见侧栏上使用 ⌘ + 滚轮可调整侧栏宽度。若三指手势与系统冲突，可将 Mission Control 和桌面切换设为四指，并关闭系统的“三指拖移”。

隐藏保留已打开的内容，也让音频和终端任务继续运行。窗口布局与内容状态可在重启后恢复；终端恢复规则见下文。

### 快捷键优先

打开、搜索、切换、定位、阅读和播放都有快捷键。从总览选中箔片，再调整位置、尺寸或播放状态，尽量减少在鼠标与键盘之间来回切换。

以下为精选默认键位。除全局总览外，需浮箔处于前台；部分操作取决于内容类型。

| 操作 | 默认快捷键 |
| --- | --- |
| 快速打开 | ⌘P |
| 箔片总览（全局） | ⌃⇧Esc |
| 打开剪贴板内容 / 无痕打开剪贴板 | ⇧⌘V / ⌥⌘V |
| 新建无痕箔 / 切换当前箔的无痕模式 | ⇧⌘N / ⌥Esc |
| 切换置顶 / 切换边框（支持的内容） | ⌘T / ⌘B |
| 增加 / 降低不透明度 | ⇧⌘↑ / ⇧⌘↓ |
| 放大 / 缩小内容；恢复实际大小 | ⌘+ / ⌘−；⌘0 |
| 窗口适合图片 / 图片适合窗口宽度（需显示边框） | ⌘[ / ⌘] |
| 搜索当前内容 / 下一个、上一个匹配 | ⌘F / ⌘G、⇧⌘G |
| EPUB 上一章 / 下一章 | ← / → |
| 播放 / 暂停；后退 / 前进（音视频） | 空格；← / → |
| 文档或字幕样式（支持的内容） | ⌘I |
| 重新读取本地文件或刷新网页 | ⌘R |
| 收藏当前箔 | ⌘D |
| 提取图片文字（光栅图片） | ⌘E |
| 保存内容图片 / 另存为 | ⌘S / ⇧⌘S |
| 重置为空箔 | ⇧⌘K |

在“设置 → 快捷键”中按名称、适用范围或按键搜索命令，修改键位或恢复默认；菜单显示当前生效的键位。全局打开剪贴板命令可自行设置，默认无键位。可配置的普通打开快捷键自动加 ⌥ 生成无痕版本，因此普通键位不接受 ⌥；⌥⌘V 固定用于无痕剪贴板。标准菜单命令如新建、隐藏不在此配置列表中。

完整说明见应用“帮助”菜单中的快捷键一览，或[快捷键文档](foofoil/Resources/zh-Hans.lproj/KeyboardShortcuts.md)；应用内版本会显示当前配置的键位。

## 音乐与视频，也可以是一张箔

从桌面角落的一张专辑封面，到带字幕的视频窗口，浮箔将实用的播放能力融入同一套箔片操作。音频与视频共用播放控制和导航方式；开始播放另一张箔时，旧输出会暂停。

### Hi-Fi：从无损专辑到 DSD 与 SACD

除 MP3、AAC、ALAC、FLAC、WAV、AIFF 等常见音频外，浮箔也把 **DSF、DFF、SACD ISO 与 APE/CUE** 纳入同一个原生 macOS 播放体验：

- **DSD 与 DoP 输出。** DSF、raw DFF 通过 DoP 输出到兼容 DAC，已验证 DSD64、DSD128、DSD256。
- **直接播放 SACD ISO。** 读取未压缩立体声区域，以曲目列表浏览、切轨和定位，无需先转换为 DSF。
- **APE 与 CUE 分轨。** 解码 Monkey’s Audio，按 CUE 浏览整张专辑中的曲目；APE 使用 CoreAudio 独占 PCM 输出。
- **采样率自动适配。** 独占 PCM 播放时，自动将输出设备采样率切换为音源采样率，无需逐曲手动调整；设备须支持对应采样率。
- **选择输出设备。** 在播放界面选择音频设备；独占播放切换时协调设备释放，让格式、曲目列表与输出控制留在同一张箔中。

DSD 播放需要支持 DoP 的输出设备，不提供 DSD 转 PCM 回退。DST 压缩和 SACD 多声道尚不支持；CUE 需保留配套音频文件。实际可用采样率取决于音源与设备能力。

### 日常视频与 Apple Music

视频支持 MP4、MOV、M4V，以及随应用交付的视频模块提供的 MKV、AVI 播放，覆盖 H.264、HEVC、Xvid 视频和 DTS、TrueHD 等常见音轨；可切换音轨及字幕。具体兼容性取决于容器、编码及其组合。

外部字幕支持 SRT、ASS/SSA、WebVTT，可同名自动匹配、手动载入或拖入，字幕文件关联随历史保存。文字字幕可调整字体、字号、颜色、背景、阴影、位置和延迟；PGS 保留图形外观，支持位置和延迟调整。⌘S 可保存当前视频画面，并选择是否包含字幕。

Apple Music 支持浏览、搜索资料库，以及将歌曲、专辑和公开歌单分享链接打开为音乐箔，无需先加入资料库。此功能默认关闭，可在“设置 → 类型 → 音频与视频”启用；访问需要授权，播放取决于账号资格和地区可用性。

## CLI 与 Agent 协作

随应用交付的原生 **`foil` CLI** 让脚本和 Agent 把参考资料直接放到桌面上：展示一份 Markdown 计划、一张图片或 SVG 图示，内容变化后显式更新，保留原有窗口布局且不抢焦点。临时资料可用无痕模式。

应用安装到“应用程序”后，可安装 CLI：

```sh
/Applications/foofoil.app/Contents/MacOS/foil install
~/.local/bin/foil --version
```

将 `~/.local/bin` 加入 PATH 后：

```sh
# 为 Agent 新建只读展示窗口
foil show ./plan.md --title '工作计划' --caller 'My Agent' --json
foil show ./diagram.svg --incognito --json

# 临时展示管道中的 Markdown
printf '# 当前进度\n正在检查实现。\n' | foil open --stdin --type markdown

# 查看所有箔片，或创建交互式终端
foil list --scope all --json
foil terminal create --title Dev --cwd ~/project --command 'git status'
```

`show` 返回的 `board_id` 可用于 `foil update BOARD_ID ./plan.md`，以及后续关闭操作。`show` / `update` 面向当前 Agent 所属的只读展示窗口，支持本地 UTF-8 文本、代码、Markdown、光栅图片和 SVG；Markdown 不加载关联图片，源文件须由调用方保留，文件变化后需显式更新。通用 `open`、`reveal`、`hide`、`inspect`、`set` 和 `terminal create` 则用于普通打开、窗口控制和终端创建；列出或关闭通用窗口需显式使用 `--scope all`。

可将[随附 Skill](skills/foofoil/SKILL.md)交给支持该格式的 Agent。安装、作用域及错误处理见 [Agent 展示与 CLI 使用说明](docs/agent-terminal-usage.zh-CN.md)，通用控制见[终端箔与通用控制](docs/terminal-foil-usage.zh-CN.md)。Developer ID、公证和干净机器上的 CLI 分发验收仍待完成。

### 交互式终端箔

“文件 → 打开终端…”可创建 zsh / bash 交互式终端，设置工作目录、环境变量和可信初始化脚本，运行 SSH、Vim 或其他终端程序。终端同样支持置顶、透明度、快捷键定位和文档样式设置。

隐藏保留任务；关闭活动任务前需要确认。主动从历史重开会创建新会话并执行保存的可选脚本；应用自动恢复时停在待启动状态，不自动执行脚本。普通终端保留最近最多 500 行、128 KiB 的只读输出记录，无痕终端不保存这些记录。详细行为见[使用说明](docs/terminal-foil-usage.zh-CN.md)。

## 阅读、预览与保存

| 内容 | 主要能力 |
| --- | --- |
| 图片与 SVG | 缩放、适应窗口；光栅图片提取文字或主体，SVG 调整颜色 |
| 文本、代码与 Markdown | 只读阅读、离线语法着色、代码行号、Markdown 标题导航、自定义字体与阅读样式 |
| PDF 与 EPUB | 翻页、章节／目录导航、阅读位置恢复；EPUB 支持全书搜索，不支持 DRM 加密书籍 |
| CSV | 以表格浏览行列数据 |
| 网页、HTML 与网页归档 | WebKit 浏览、内容搜索、保存网页归档 |
| Office 与其他文档 | 可选择文字的只读预览或系统 Quick Look；效果取决于格式和系统预览能力 |
| 目录与压缩包 | 文件树、嵌套包浏览、包内文件预览、导出所选文件或目录 |
| 摄像头 | 实时画面与截图 |

ZIP、TAR 及其常见压缩变体、7z、RAR，以及漫画包、APK、JAR、KRA 和 ISO 9660 镜像可按目录树浏览。内层包在展开时读取，包内文件只读预览，不自动提取关联资源。Office ZIP 容器和 EPUB 保留正常预览，并提供“打开包内容”。加密 7z/RAR、ZIP 分卷和部分算法组合尚不支持；详细范围与限额见[压缩包实测报告](docs/archive-preview-verification.zh-CN.md)。

**⌘S 保存当前可见内容图片**，默认 HEIC，可选 PNG 或 JPG；文档保存正文视口，音频保存可用的封面。**⇧⌘S 另存源文件或完整文本**，网页保存为 `.webarchive`，Markdown 可导出 HTML。摄像头、CUE、SACD ISO 和 Apple Music 不提供另存为；终端使用此命令导出保留的输出记录。

完整格式与限制见应用“帮助 → 支持的内容”，或[支持内容一览](foofoil/Resources/zh-Hans.lproj/SupportedContent.md)。

## 快速开始

1. 启动浮箔，在空箔中输入关键词、网址或文件路径；也可以按 ⌘O 打开文件、⇧⌘O 打开目录，或直接拖入内容。
2. 复制一段文字或图片，按 ⇧⌘V 打开；右键查看当前内容可用的操作。
3. 按 ⌘T 置顶，用 ⌘ + 拖动移动箔片，或用 ⌃⌥ 九宫格快捷键定位。
4. 按 ⌃⇧Esc 打开总览，在多张箔片、历史和搜索结果间切换。

从 Finder 打开：将浮箔放入“应用程序”并启动一次，选中文件或文件夹，通过“Finder → 服务 → 在浮箔中打开”送入浮箔。可在“系统设置 → 键盘 → 键盘快捷键 → 服务”中启用并分配快捷键；若服务尚未出现，退出并重新登录 macOS 后再检查。系统共享入口可通过“设置 → 通用 → 共享菜单”前往系统设置启用。

## 历史、文件与无痕模式

历史、收藏、托管内容与缓存保存在本机，OCR 和内容索引在设备端完成。加载网页、远程资源与 Apple Music 需要网络连接。

本地文件直接引用原件，通过书签尽可能跟踪改名或移动；历史不备份原文件正文，删除历史也不会删除原件。剪贴板文字、Markdown、HTML 和图片数据会自动保存，供历史恢复；复制的文件仍引用原件，网址和图片地址作为网址打开，不自动下载。系统共享的临时附件会保存到本地供恢复。

“自动清理找不到文件的历史记录”默认开启，只清理确认丢失且未收藏的文件记录；离线卷、授权问题及暂时不可用的来源保留。托管正文不受普通缓存容量淘汰；删除历史后，已打开的窗口仍可使用，最后一个使用者释放后才清理正文。

**无痕箔不进入浮箔历史，也不在退出后恢复。** 可新建无痕箔、切换当前箔模式，或使用无痕打开快捷键和系统共享入口。无痕不阻止网页下载落盘，也不改变 Shell 自身的命令历史配置。

## 从源码构建

### 系统要求

- macOS 26.5 或更高版本。
- 从源码构建需要支持项目所配置 macOS SDK 的 Xcode。

完整开发环境使用以下兄弟仓库布局：

```text
workspace/
├── foofoil/        # 应用、窗口、内容展示、搜索与 CLI
├── extension-kit/  # 必需的内部模块契约 Swift 包
├── hifi/           # Hi-Fi 音频
├── ebook/          # EPUB 解析与阅读
└── video/          # 增强视频播放
```

在 `foofoil` 仓库运行：

```sh
./run
```

脚本构建 Debug 应用，构建并嵌入 Hi-Fi、EPUB 和视频模块，然后重启浮箔。缺少某个模块的 `build-plugin` 时会跳过，相应能力不可用。视频默认包含，可用 `./run --without-video` 排除。

包含视频模块时，首次构建需要联网从 `ffmpeg.org` 下载固定版本的 FFmpeg 源码（约 11 MB），校验 SHA-256 后在本机编译，无需手动安装 FFmpeg。下载和编译产物缓存在 `video/.build/`，后续构建复用缓存；损坏的下载缓存会自动重新下载。首次运行或打包可能因此耗时较长，下载失败后可直接重试原命令。

使用 Xcode 联合编辑时打开 `foofoil.xcworkspace`，选择 `foofoil` Scheme 和 **My Mac**，按需配置开发签名团队。Xcode ⌘R 不会构建并嵌入相邻模块；验证完整内容体验请使用 `./run`。

仅构建主应用：

```sh
xcodebuild build \
  -project foofoil.xcodeproj \
  -scheme foofoil \
  -configuration Debug \
  -destination 'platform=macOS'
```

运行测试套件：

```sh
xcodebuild test \
  -project foofoil.xcodeproj \
  -scheme foofoil \
  -destination 'platform=macOS'
```

### 模块与打包

Hi-Fi、EPUB 和视频随应用统一交付，用户无需安装、启用或更新插件。源码中的扩展／插件是内部开发机制；相关 ABI、Manifest 和保留的管理代码见[模块开发说明](docs/extension-support.zh-CN.md)。

`./package-dmg` 构建 Release 应用、嵌入上述模块并生成 DMG，完整默认打包需要上述五个仓库。`--without-video` 可排除视频模块；`--no-sign` 生成本地验证包，`--sign` 使用 Developer ID 签名与公证，需要配置相应凭据，见脚本头部。

## 轻量化设计与贡献

浮箔优先使用 SwiftUI、AppKit、WebKit、PDFKit、Vision、AVFoundation、CoreAudio、ImageIO 和 SQLite3 等系统能力。“轻量”是一项持续的实现原则：控制依赖、复用原生能力，避免重复携带系统已经提供的基础设施。Markdown 使用 cmark，源码着色使用离线 highlight.js，交互式终端使用 SwiftTerm；依赖及许可见[第三方声明](THIRD_PARTY_NOTICES.md)。

欢迎参与开发。请先阅读 [CONTRIBUTING.md](CONTRIBUTING.md) 和 [AGENTS.md](AGENTS.md)，保持改动聚焦，兼顾响应速度、原生交互、无障碍、本地化与用户文件安全。
