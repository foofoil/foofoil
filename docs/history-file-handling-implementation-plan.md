# foofoil 历史记录与文件处理：独立前置实施任务

> 2026-10-16 · 计划文档，未据此实施功能。每项完成后填写验证证据再勾选。
> 本任务独立于 Agent 接入，可单独实施和验收；完成后才能开始 [Agent 实施计划](foofoil-agent-desktop-terminal-implementation-plan.md) 的 S07。

## 1. 目标与确定规则

依据来源统一行为，而不是按图片／视频等文件类型区分。已有原文件的内容直接引用；剪贴板提供的正文由浮箔自动保存，不要求用户另存为。Agent 只读文件入口不因此获得剪贴板、便笺或写文件能力。

| 来源 | 普通箔历史 | 文件归属与删除 |
| --- | --- | --- |
| 本地原文件，包括 Finder 复制的文件 | 保存引用、书签与展示状态 | 用户拥有；浮箔不复制正文，不删除原文件 |
| 网址，包括仅复制图片地址 | 保存网址与展示状态 | 不因本任务自动下载归档 |
| 剪贴板文本／Markdown／HTML | 自动保存托管正文，标记来自剪贴板，可从历史恢复 | 浮箔拥有；删除历史后清理，无活动使用者后实际删除 |
| 剪贴板图片数据 | 自动保存托管图片，标记来自剪贴板，可从历史恢复 | 与剪贴板文本采用相同生命周期 |
| 无痕剪贴板内容 | 不写历史、不恢复 | 仅会话持有；释放后清理临时资源 |

网页“复制图片”可能同时提供图片数据、网址和 HTML；以实际表示判断。优先级为文件引用、图片数据、网址／文本等原有内容识别。图片附带的网址只作可选来源信息，图片历史不依赖重新下载。保留像素不等于保证保留网页原始文件的格式、动画或元数据。

外部文件用书签优先追踪改名和移动；不能定位且确认丢失时，默认自动删除历史。设置“自动清理找不到文件的历史记录”默认开启，可以关闭；授权问题、卷离线和暂时错误不等同于丢失。

托管正文是剪贴板历史的实际内容，不是可随时淘汰的缩略图缓存。有效历史引用期间必须保留；删除历史时释放正文、索引及派生资源，只删除浮箔拥有且不再被使用的文件。当前窗口使用中时延迟删除，不强制关窗，不重新创建已被用户删除的历史。

GUI 现有截图、便笺和临时分享工作流保持便利，不新增强制另存为或便笺保存确认作为本任务需求。盘点其托管来源并复用同一所有权规则；其具体编辑行为不扩展到 Agent。

## 2. 执行与交接约定

- 先读当前用户指令和适用 `AGENTS.md`；跨兄弟仓库时读取对应指令。使用 GitButler，保护其他会话修改，不自动提交、推送或发布。
- 每步先检查实际源码，不因文档的历史描述假定能力缺失。按前置依赖推进，专项和通用 Checklist 均通过后才标为完成。
- 本文不授权清空开发数据、删除唯一内容副本或扩大权限；旧数据处置单独列清单，不在文档任务中执行。
- 使用现有设置、历史数据库、索引和缓存设施，不建设第二套持久化体系或存储模式选择界面。
- 有代码变化时运行相关测试并按仓库要求执行 `./run`；真实交互或 Release 验证缺失时标记待验证，不编造结果。

## 4. 分步实施 Checklist

### H01：盘点实际行为并建立基线

入口：`AppState/AppState+ContentOpen.swift`、`AppState+Cache.swift`、`AppState+Persistence.swift`、`AppState+Init.swift`、`AppDelegate` 各打开入口、`ShareSupport`、`ExtensionSupport` 和兄弟内容模块。

交付清单：

- [ ] 新建 `docs/file-reference-baseline.zh-CN.md`，逐项记录图片／SVG、文本／Markdown／CSV／代码、PDF、HTML／网页归档、Quick Look、音视频、EPUB、压缩包、文件列表及分享入口的当前行为。
- [ ] 清单记录实际读取路径、是否复制／转码正文、书签来源、历史 ID、恢复路径、缓存所有者及对应测试，不仅记录 README 声称的能力。
- [ ] 单独列出无源剪贴板、截图、便笺、摄像头、内置帮助文档和非文件型媒体；不将它们错误归类为失效本地文件。
- [ ] 盘点历史删除对数据库、全文索引、缩略图、在途索引任务和窗口恢复配置的影响。
- [ ] 准备小型本地测试夹具，覆盖文件改名、移动、删除、同路径替换、不可读及关联资源；测试只操作临时目录。
- [ ] 运行当前相关测试，记录基线失败、环境限制与可复现命令，不把既有失败算作新通过结果。

通过条件：每条持久正文复制与恢复路径都有归属和后续改造步骤；现有问题能与本次回归区分。

### H02：统一原文件引用与授权生命周期

入口：`SettingsStore.swift` 中 `WindowConfig`、`AppState+MediaType.swift` 中书签辅助方法、`AppState+ContentOpen.swift` 中媒体访问恢复、`AppState+Persistence.swift`。

交付清单：

- [ ] 在现有模型中表达原文件定位、必要书签及派生缓存用途，不新增 snapshot/reference 双模式。
- [ ] 优先复用现有 URL、书签和配置设施；仅在能消除真实重复时提取小型共享辅助类型，不建设通用资源管理框架。
- [ ] 分开处理“定位到文件”和“有权读取文件”；不以 `fileExists` 为假直接认定删除。
- [ ] 定位结果区分可用、确认丢失、需重新授权、存储离线和暂时失败；未知状态保守保留。
- [ ] 书签能跟随改名／移动时刷新引用；书签过期但仍可解析时更新书签。
- [ ] 明确访问权何时取得、转交、释放；关闭、替换、失败和取消均释放本次拥有的访问权，避免重复结束他人访问。
- [ ] 保留来源信息供展示和去重；缓存路径不能伪装成原文件来源。
- [ ] 测试可读、改名／移动、无授权、失效书签、暂时失败及访问权释放；无法在测试中模拟的真实沙盒行为列入手工验证。

通过条件：基础模型支持直接读取与当前版本恢复；没有扩大沙盒权限或改变部署目标。

### H03：逐入口取消本地正文持久复制

入口：`AppState+ContentOpen.swift`、`AppState+ClipboardContent.swift`、`AppState+Cache.swift`、`Views/WebView.swift`、`Views/PDFModeView.swift`、`Archive`、`ExtensionSupport`、`ShareSupport`。

按下面每项独立修改和验证，避免一次替换所有 `cache*` 调用：

- [ ] 图片／SVG：读取原文件，取消为保管内容而复制或转为 HEIC；缩略图仍可派生，不修改原文件。
- [ ] 文本／Markdown／CSV／代码：读取原文件，历史保存引用；显式重新打开读取当前内容，编辑能力不因本步骤自动对外开放。
- [ ] PDF 和 Quick Look：直接引用并恢复授权，检查当前经图片或媒体通道承载的路径。
- [ ] 本地 HTML／网页归档：引用原文件，维持受限资源访问，不通过复制到应用缓存获取隐式能力。
- [ ] 音视频与 EPUB 等模块：核对并统一引用和恢复行为，不把宿主或模块状态文件误删为正文副本。
- [ ] 压缩包／文件列表：保存原容器或原文件引用；临时提取属于有界派生资源，不生成独立可恢复正文。
- [ ] 文件关联、Finder 服务、拖放、快速打开、历史恢复和分享真实文件入口都采用统一行为。
- [ ] 将只有临时导出的分享内容交给 H04，不假装取得了稳定原文件引用。
- [ ] 原文件同路径替换后显式刷新有效；失效缩略图、OCR 和索引按文件变化重新生成。
- [ ] 验证原文件删除后不能靠旧正文缓存从历史重新打开；当前已解码画面可暂存内存，但不承诺可恢复。
- [ ] 按类型运行聚焦测试；手工核对拖放、打开、重启恢复以及多窗口引用同一文件。

通过条件：H01 清单中的本地文件入口均已处理或明确证明无需修改；不存在按类型隐式归档正文的遗漏。

### H04：剪贴板自动保存、来源标记与缓存归属

入口：`AppDelegate+Actions.swift` 的剪贴板读取、`AppState+ClipboardContent.swift`、`AppState+Cache.swift`、`ContentSaving.swift`、历史仓库、`ShareSupport`。

交付清单：

- [ ] 剪贴板文件引用走 H03 原文件路径，网址走现有网址打开路径。
- [ ] 剪贴板文本／Markdown／HTML 自动写入应用托管文件，普通箔进入历史，无需另存为。
- [ ] 剪贴板图片数据自动保存为托管图片；保留可直接使用的图片表示，需编码时优先无损 PNG，避免仅为统一缓存而有损转码。
- [ ] 文件引用优先于图片表示，图片数据优先于附带网址／HTML；“复制图片地址”仅有网址时仍打开网址，不擅自下载归档。
- [ ] 来源明确标记为“来自剪贴板”，历史卡片／信息面板可识别；不要把托管文件路径显示为用户原文件来源。
- [ ] 在模型中区分外部原文件、应用托管内容和派生缓存的所有权，复用现有字段及必要的最小扩展；不增加用户可选存储模式。
- [ ] 历史删除统一释放其托管正文及派生缓存；仍有窗口、其他历史或在途任务使用时延后删除，最后一个使用者释放后清理。
- [ ] 删除历史不关闭当前窗口；防止窗口随后自动保存或在途索引将用户删除的记录重新写回。
- [ ] 无痕剪贴板内容不进历史、不恢复；只保留会话所需内存／临时文件，最后一个使用者释放后清理，异常退出残留在后续启动安全回收。
- [ ] 托管正文不能按普通可重建缓存容量淘汰；有有效历史引用时应保留。正文已丢失的托管历史依据 H05 的清理设置处理，不尝试从系统剪贴板或来源网址重建。
- [ ] 文本内容后续编辑沿用 GUI 能力并保存到其托管正文，避免正文与历史状态分叉；不向 Agent 暴露编辑接口。
- [ ] 剪贴板 HTML 保存片段本身，不递归下载网页资源；图像作为独立图片表示存在时按图片处理。
- [ ] 截图、GUI 便笺和仅有临时导出的分享入口不再强制改为“另存为才进历史”；盘点并保留其现有人工工作流，用应用托管来源表达需要自持的正文，不把它误当可追踪外部原文件。
- [ ] 测试文件／图片／网址混合表示、文本／HTML、来源标记、重启恢复、删除历史后延迟释放、共享引用、无痕和异常退出残留回收。
- [ ] 手工验证浏览器“复制图片”和“复制图片地址”、Finder 复制文件、截图复制及复制文本；记录应用和实际剪贴板表示，不假设每个浏览器提供相同格式。

通过条件：用户粘贴内容后无需另存为即可从普通历史恢复；缓存生命周期跟随历史及活动使用者，无痕不留下可恢复记录。

### H05：可配置的失效历史自动清理

入口：`SettingsStore.swift`、`Views/GeneralSettingsView.swift`、`History/HistoryRepository.swift`、`HistoryDatabase.swift`、`History/Indexing`、历史打开和启动恢复入口。

交付清单：

- [ ] 新增“自动清理找不到文件的历史记录”，默认开启；英／简中本地化完整。
- [ ] 基于 H02 定位结果判定，不对单次读取失败或权限错误直接执行删除。
- [ ] 启动后后台有界检查、查看历史时按需复查、打开／恢复前检查；不增加常驻监听或主线程全量扫描。
- [ ] 能追踪改名／移动则刷新引用并保留；卷离线、需授权、暂时失败或未知原因均保留。
- [ ] 确认丢失且设置开启时，统一删除仓库记录、搜索索引及对应待恢复配置。
- [ ] 处理在途 OCR／索引任务，防止已删记录被异步结果重新写回。
- [ ] 删除前重新确认设置仍开启、记录及来源未变化；重复清理幂等。
- [ ] 清理无引用派生缓存时检查其他历史、当前窗口与在途任务；不删除原文件，不强制关闭窗口。
- [ ] 关闭设置保留失效项并在打开时明确反馈；重新开启在下次检查生效。
- [ ] 文件列表仅部分条目丢失时移除失效条目并保留可用条目；全部确认丢失时才清除整个本地文件历史项。原容器丢失按容器历史处理。
- [ ] 网页、内置帮助和非文件型媒体不参与外部文件丢失判断；剪贴板托管内容检查其托管正文是否确实丢失，不能因没有外部原路径而删除。
- [ ] 测试默认值、开关切换、确认丢失、改名、离线、权限、异步竞态、共享缓存与部分列表失效。

通过条件：开启时清理确定失效项，关闭时保留；不因离线或授权问题误删。

## 5. 独立验收 Checklist

- [ ] 不同类型本地文件都引用原文件；删除历史永不删除用户原文件。
- [ ] 文件改名／移动后能追踪则保留，确实丢失且设置开启则删除历史、索引和待恢复配置。
- [ ] 设置关闭时失效记录保留；离线、需授权和暂时错误始终不误删。
- [ ] 普通剪贴板文本与图片无需另存为即可跨重启恢复，来源标记清楚。
- [ ] 删除剪贴板历史释放对应托管正文；活动窗口与共享引用延迟释放，最终无遗留。
- [ ] 删除历史后关闭窗口或完成索引不会复活该历史；无痕内容不写历史或重启恢复。
- [ ] 托管正文不会因普通缓存淘汰而丢失；派生缓存可以安全重建。
- [ ] GUI 剪贴板、截图、便笺、分享和媒体能力保持便利，没有新增强制另存为流程。
- [ ] 聚焦测试及完整测试通过，执行 `./run` 并记录真实手工验收；未通过项明确保留。
- [ ] H01—H06 状态和证据完整，通知 Agent 计划此前置门槛已通过。
